# كنافة البشوات — ملفات الموقع

## محتويات المشروع
- `index.html`: الصفحة الرئيسية بالعربية.
- `style.css`: التصميم الأسود والذهبي والمتجاوب للجوال.
- `script.js`: روابط الطلب عبر واتساب.
- `images/`: صور المنتجات المرفوعة.

## نشر الموقع على GitHub Pages
1. افتح مستودع المشروع على GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع ملف ZIP فقط).
3. من Settings ثم Pages، اختر النشر من فرع `main` ومجلد `/(root)` إذا لم يكن مفعلاً.
4. انتظر انتهاء النشر ثم افتح رابط الموقع.

# مشروع كنافة البشوات

## الملفات
- `index.html`: واجهة المتجر العامة.
- `style.css`: تصميم المتجر.
- `script.js`: قراءة المنتجات وعرضها وروابط الطلب عبر واتساب.
- `admin.html` و`admin.css` و`admin.js`: لوحة تسجيل دخول وإضافة وتعديل وحذف المنتجات ورفع صورها.
- `supabase_setup.sql`: إعداد سياسات Supabase وجدول المديرين وحاوية الصور.

## إعداد لوحة الإدارة لأول مرة
1. افتح مشروع Supabase الصحيح وتأكد أن رابط المشروع يطابق الرابط الموجود في `script.js` و`admin.js`.
2. من **SQL Editor** راجع `supabase_setup.sql` ثم شغّله. هذا يضيف سياسات الإدارة وحاوية الصور؛ لا تشغّل SQL على مشروع خاطئ.
3. في Supabase افتح **Authentication → Users → Add user** وأنشئ حساب بريد إلكتروني وكلمة مرور قوية للمدير. أكمل تأكيد البريد حسب إعدادات مشروعك.
4. انسخ **User UID** الخاص بالحساب.
5. في **SQL Editor** نفّذ الأمر التالي مع استبدال `PUT-USER-UUID-HERE` بالـ UID الذي نسخته:

```sql
insert into public.admin_users (user_id)
values ('PUT-USER-UUID-HERE');
```

هذا الإجراء اليدوي مقصود: الزائر لا يستطيع منح نفسه صلاحية مدير. لا تضع `service_role` أو `Secret key` في أي ملف HTML/JavaScript.

## استخدام لوحة الإدارة
1. ارفع جميع ملفات المشروع إلى نفس مجلد الاستضافة أو شغّلها عبر خادم محلي.
2. افتح `admin.html` من نفس موقع المتجر.
3. سجّل الدخول بحساب المدير الذي أنشأته.
4. أدخل الاسم والتصنيف والسعر والوصف. اختر صورة من جهازك أو أدخل رابط صورة مباشر، ثم اضغط **إضافة المنتج**.
5. لتعديل منتج اضغط **تعديل**، ولحذفه اضغط **حذف**. ستتحدّث قائمة المتجر عند إعادة تحميلها.

## قاعدة البيانات والمفاتيح
- جدول المنتجات الحالي: `public.products`، بالأعمدة `id`, `name`, `description`, `price`, `image_url`, `category`.
- رابط Supabase ومفتاح Publishable العام موجودان في `script.js` و`admin.js` لاستخدام المتصفح. الـ Publishable key مصمم للاستخدام العام مع سياسات RLS صحيحة.
- لا تستخدم `service_role` أو `Secret key` في الواجهة الأمامية.
- سياسات RLS تمنح الجميع القراءة فقط، وتسمح بالإضافة والتعديل والحذف والرفع لحسابات `admin_users` فقط.
- إذا كانت لديك سياسات قديمة إضافية تسمح بالكتابة للـ `anon`، راجعها واحذفها من إعدادات Supabase؛ السياسات permissive قد تسمح بعمليات أكثر مما تتوقع.
- رفع الصور يتطلب تنفيذ إعدادات `supabase_setup.sql` وإنشاء حساب مدير وإضافته إلى `admin_users`.

## ملاحظات
- عملة السعر في المتجر مضبوطة حاليًا على `ر.س` داخل `script.js`؛ عدّلها إذا كنت تستخدم عملة أخرى.
- تأكد من رقم واتساب في `script.js` قبل النشر.
